## Medium 发现

### AUD-TOOL-002 · 发布路径绕过仓库自带的全部检查（复现项）

- 类别 testing / 置信 95 / 状态 open / 处置 Add Guard
- 证据：`package.json:15` `"deploy": "npm run build && wrangler deploy"`；`check`、`test`、`check-urls`、`test:browser` 均不在链路上；仓库无 `.github`。上一轮审计已提出同一建议，仍未落地。
- 影响：一次跳过手工检查的 deploy 就能把旧地址失效、草稿泄漏或交互回归直接推给读者。
- 建议：`"predeploy": "npm run check && npm test && npm run check-urls"`。建议验证状态 **Strongly Supported**。

### AUD-TYPE-001 · 构建核心 .mjs/.js 完全未纳入类型检查

- 类别 maintainability / 置信 95 / 处置 Fix
- 证据：`tsconfig.json:2` 仅 `extends "astro/tsconfigs/strict"`，其链上 `allowJs: true` 且从未设 `checkJs`；`grep -rln "@ts-check" src scripts` 返回空。仓库有 14 个 `.mjs`/`.js`，其中 [src/lib/content-dates.mjs:1](file:///E:/Repos/Blog_Astro/src/lib/content-dates.mjs) 共 262 行负责 Git 历史快照与更新时间签名，[src/pages/rss.xml.js:15](file:///E:/Repos/Blog_Astro/src/pages/rss.xml.js#L15) 为公开端点。`npm run check` 报「86 files / 0 errors」并不覆盖这些文件的函数体。
- 影响：最关键最复杂的构建期逻辑没有静态保障；改 `posts.ts` 的类型不会阻止 `content-dates.mjs` 里的字段名或 URL 漂移。
- 建议：逐文件加 `// @ts-check`（可增量），或把 `rss.xml.js` 直接改成 `.ts`。

### AUD-ARCH-001 · 文章 URL 公式两份实现且无一致性守卫

### AUD-A11Y-002 · 无跳转正文链接，换页后焦点落回 body

- 类别 accessibility / 置信 95 / 处置 Fix
- 证据：实测生产预览，从首页点卡片完成客户端换页后 `document.activeElement === BODY`；`src/layouts/Base.astro:107` 的 `<main>` 无 `id` 也无 `tabindex`；全仓 grep 无 skip-link。顶栏导航在每页重复。
- 影响：键盘/读屏用户无法跳过重复导航（WCAG 2.4.1 A 级），换页后拿不到新页面标题播报。
- 建议：`<main tabindex="-1" id="main">` + `astro:after-swap` 聚焦 + 一条跳转正文链接。

### AUD-A11Y-003 · 桌面目录侧栏不随章节跟踪自滚

- 类别 ux / 置信 95 / 处置 Fix
- 证据：实测 1280×420 打开长文滚到 75%：`.toc` 可视 `top=97 / height=291 / scrollHeight=453`，带 `aria-current` 的活动项 `top=432`（已在侧栏下方），而 `.toc.scrollTop` 仍为 `0`。窄屏面板有居中逻辑（[src/lib/header.ts:41](file:///E:/Repos/Blog_Astro/src/lib/header.ts#L41)），宽屏侧栏没有（[src/lib/toc-tracking.ts:9](file:///E:/Repos/Blog_Astro/src/lib/toc-tracking.ts#L10) 只切 `aria-current`）。
- 影响：长文阅读时目录高亮不可见，桌面目录的核心价值失效。
- 建议：对活动项 `scrollIntoView({ block: 'nearest' })`，reduced-motion 下 `behavior: 'auto'`；与窄屏面板共用实现。

### AUD-UX-001 · 禁用 JS 时移动端只剩一个可见但失效的汉堡按钮

### AUD-PERF-001 · GLightbox 打进全部文章页，实际只有 4/16 篇需要

- 证据：[src/lib/lightbox.ts:3](file:///E:/Repos/Blog_Astro/src/lib/lightbox.ts#L3) 静态 `import GLightbox`，经 `article-behaviors.ts:2` 进入 Post 脚本。实测 `dist/_astro/Post.astro_..._-jU_FAOy.js` = **58,472 B / gzip 16,333 B**，占文章页 JS 总量（约 88 KB）的三分之二；无正文图的《猫》等 12 篇 HTML 同样引用它。逐篇统计正文含图文章仅 4 篇。

## 已核实为健康的区域

以下均由本轮实测确认，不是推断：

1. **减少动效是真的全量降级**：`reducedMotion: 'reduce'` 下抽查 6 类元素计算值均为 `transition: all 0s` / `animation: none`，`scroll-behavior` 变 `auto`；JS 侧灯箱、进度条、主题切换各自查 `matchMedia` 并监听 `change`。
2. **交付稳定性**：3 个代表页面（首页 / 8 图长文 / 29 代码块长文）实测 **CLS = 0**，零 `layout-shift` 条目；24 个页面×视口组合（375/768/1440）零 `pageerror`、零文档级横向溢出；正文图片全部带 `width`/`height` 与 `loading="lazy"`。
3. **主题链路**：auto→浅色→深色→auto 三态循环正常，`localStorage` 持久化、刷新后保持、客户端换页后保持，`meta[name=theme-color]` 同步更新；深色实测正文 14.54:1、辅助文字 7.03:1、正文链接 9.52:1、行内代码 13.36:1，全部高于 AA。
4. **锚点与焦点**：`base.css:8` 的 `scroll-padding-top: calc(var(--header-height) + var(--space-4))` 实测生效（点目录后标题落在 88px，粘性头部底边 65px，不被遮挡）；`:focus-visible` 统一 2px 实线强调色 + 4px 偏移；灯箱 dialog 有名称、`aria-modal=true`、初始焦点在关闭按钮、Esc 后焦点回到触发链接、`body` 溢出还原。
5. **样式令牌**：`src/styles` 内 0 处硬编码 hex，颜色全部由 `theme.ts` 生成；间距/字号/动效走 `var()`；全站仅一个 webfont 子集（`NotoSerifSC-Bold.woff2` 86,900 B，`font-display: swap` + preload），且所有衬线用法均为 700 字重，无合成字重风险。
6. **构建与仓库卫生**：`git status` 干净、`origin/main` 与本地一致、`dist`/`.astro`/`.wrangler` 均被忽略且未入库、`.git` 14 MiB / `garbage: 0`；`ensure-git-history.mjs` 在历史不完整时硬失败并挂在 `prebuild`，构建可复现性这一环是闭合的。
